# ملهم طباعة

## تشغيل على جهازك (أسرع طريقة)
1. نزّل Node.js (النسخة LTS) من nodejs.org
2. افتح CMD جوه الفولدر ده واكتب:
   npm install
   npm start

## عمل ملف exe بدون تثبيت (Portable)
- على جهازك: npm run dist  → هتلاقي الـ exe في فولدر dist
- أو ارفع الفولدر على GitHub: الـ exe بيتبني لوحده من تبويب Actions (build-exe)

البيانات محفوظة في: %APPDATA%\mulhim-print\mulhim.json
